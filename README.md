# CyberCafe-Management-System-Project
Đồ án môn Công Nghệ .NET
### Hệ thống quản lý phòng máy thương mại

## Giới thiệu

Đồ án xây dựng hệ thống quản lý phòng máy thương mại, hỗ trợ quản lý máy tính, khách hàng, nhân viên, dịch vụ và hóa đơn.

## Chức năng

* Quản lý máy tính
* Quản lý khách hàng
* Quản lý nhân viên
* Quản lý dịch vụ
* Quản lý phiên sử dụng máy
* Tính tiền sử dụng máy
* Quản lý hóa đơn
* Thống kê doanh thu
* Đăng nhập và phân quyền

## Công nghệ sử dụng

* C#
* ASP.NET Core MVC
* Entity Framework Core
* SQL Server
* HTML / CSS / JavaScript
* Bootstrap

## Database

Sử dụng SQL Server.

## Cách chạy

1. Clone project về máy.
2. Mở file '.sln' bằng Visual Studio.
3. Cấu hình connection string trong 'appsettings.json'.
4. Chạy Migration để tạo database.
5. Build và chạy project.
